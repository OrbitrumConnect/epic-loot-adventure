# TRIBOS — Tribo + Base Comum (decisão selada 07/10)

## Regra

**Why:** Simplifica a gestão (uma base por tribo, não N bases), incentiva formar tribo
(somar recursos = base melhor) e dá à Camada 2 (Raid) um alvo claro: a base comum.

**How to apply:**
- **Solo:** cada jogador tem a própria base; tudo farmado individualmente (armazém próprio).
- **Formou tribo (até ~3, solo/duo/trio):** os recursos de todos são **somados** — os armazéns individuais se **mesclam** num pool único.
- Ao formar, **todos perdem a base individual**. A tribo passa a administrar **UMA base comum** numa **nova localidade**.
- A base comum já nasce com **upgrade proporcional aos recursos somados**.
- Com o pool, a tribo **escolhe qual base pegar ("base X")** — quanto mais recurso junto, melhores as opções / tier disponível.

## Cruzando com o Documento Mestre

- **Camada 3 — Base (Clash):** "a base construída VIRA o mapa que inimigos enfrentam na raid". A base comum da tribo é esse mapa.
- **Camada 2 — Raid (MOBA):** quem defende são os donos da base (online) ou NPCs/defesas (offline). Atacante vem solo/duo/trio. A base comum é o ponto físico da raid no mapa.
- **Camada 1 — Mapa Aberto:** o farm (manual agora, passivo na base depois) alimenta o pool. "Offline mantém. Online conquista."
- Gestão de tribo/cargos/alianças (Camada 3) e economia/progressão compartilhadas pelo mesmo personagem.
