- **Não force push** — Lovable conectado, não reescrever histórico git
- **Space = PULO, click esquerdo = ATTACK** — nunca inverter
- **Cliente nunca decide** — dano, HP, loot = sistema/servidor
- **Ler memória primeiro** — economiza tokens, tudo já tá mapeado
